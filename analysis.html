2025 Colts Early-Down Efficiency: When Did the Offense Break Down?¶

Play-by-play audit of the Colts' 1st and 2nd down offense across three windows of the 2025 regular season:

Segment Weeks Starting QB
Early 1–8 Daniel Jones
Late 9–13 Daniel Jones
Post-injury 14–18 Riley Leonard / Philip Rivers

The question: did the offense decline before Jones' Week 14 injury, or is the injury the real breaking point?

Run python ingest.py first to build nfl_data.db.

import sqlite3
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

conn = sqlite3.connect('nfl_data.db')
sns.set_style('whitegrid')

# Every query uses the same segment definition, so it lives in one place.
# Each segment has an explicit upper bound: nothing after Week 13 can leak into 'Late'.
SEGMENTS = ['Early (1-8)', 'Late (9-13)', 'Post-injury (14-18)']
SEGMENT_SQL = """
    CASE
        WHEN week <= 8 THEN 'Early (1-8)'
        WHEN week <= 13 THEN 'Late (9-13)'
        ELSE 'Post-injury (14-18)'
    END
"""

# Colts 2025 regular-season offensive run/pass plays
COLTS_FILTER = """
    posteam = 'IND'
    AND season = 2025
    AND season_type = 'REG'
    AND play_type IN ('run', 'pass')
"""

2. Load Colts early-down plays¶

One query pulls every Colts 1st/2nd down run or pass, tagged with its segment. The sanity check below proves each segment only contains its own weeks.

In [3]:
query = f"""
SELECT
    week,
    {SEGMENT_SQL} AS segment,
    defteam,
    down,
    ydstogo,
    play_type,
    run_location,
    yards_gained,
    epa
FROM pbp_data
WHERE {COLTS_FILTER}
  AND down IN (1, 2)
"""
colts = pd.read_sql_query(query, conn)
colts['segment'] = pd.Categorical(colts['segment'], categories=SEGMENTS, ordered=True)
colts['down'] = colts['down'].astype(int)

# Success: gain >= 4 yards on 1st down, or >= half the yards to go on 2nd down
colts['is_success'] = (
    ((colts['down'] == 1) & (colts['yards_gained'] >= 4)) |
    ((colts['down'] == 2) & (colts['yards_gained'] >= colts['ydstogo'] / 2))
).astype(int)

# Sanity check: first and last week in each segment
colts.groupby('segment', observed=True)['week'].agg(first_week='min', last_week='max', plays='count')

6. Opponent adjustment¶

Did the Colts just face better defenses later in the year? For each defense, compute the average early-down EPA it allowed to every team except the Colts, separately for each segment. Then match each Colts game to that opponent's number for the same segment.

epa_over_expected = Colts EPA − what that defense usually allowed in that stretch. Positive means the Colts did better than that defense's typical opponent.

In [9]:
query = f"""
SELECT
    defteam,
    {SEGMENT_SQL} AS segment,
    AVG(epa) AS opp_epa_allowed
FROM pbp_data
WHERE season = 2025
  AND season_type = 'REG'
  AND down IN (1, 2)
  AND play_type IN ('run', 'pass')
  AND posteam != 'IND'
GROUP BY defteam, segment
"""
def_strength = pd.read_sql_query(query, conn)

games = colts.groupby(['segment', 'week', 'defteam'], observed=True).agg(colts_epa=('epa', 'mean')).reset_index()
games['segment'] = games['segment'].astype(str)
games = games.merge(def_strength, on=['defteam', 'segment'], how='left')
games['epa_over_expected'] = games['colts_epa'] - games['opp_epa_allowed']
games['segment'] = pd.Categorical(games['segment'], categories=SEGMENTS, ordered=True)

print(games.round(3).to_string(index=False))

Findings¶

1. There was a real slide before the injury, but not a collapse. Early-down EPA fell from +0.205 (Weeks 1–8) to +0.036 (Weeks 9–13) with Jones still starting. Success rate barely moved (57.8% → 56.1%), so the offense was still staying on schedule. What it lost was big plays, and it gave up more costly negative ones.

2. The collapse came after Week 14. With the backups at QB, early-down EPA dropped to −0.191 and success rate to 42.2%. The injury narrative is mostly right about when the offense fell apart.

3. Schedule doesn't explain it. Opponent-adjusted EPA went +0.217 → +0.087 → −0.155. Weeks 9–13 defenses were only slightly tougher than Weeks 1–8 (−0.056 vs −0.014 EPA allowed), which accounts for a small part of the pre-injury drop.

4. The pre-injury slide was in the passing game. 1st-down pass EPA fell from +0.292 to +0.107 and 2nd-down pass EPA from +0.186 to −0.196. The run game held up: 2nd-down runs improved (+0.211 → +0.354) and inside runs improved (+0.059 → +0.231). Outside runs fell (+0.213 → +0.081) but stayed positive.

5. Play-calling moved toward the weaker option. In Weeks 9–13 the run/pass ratio dropped on both downs (1st: 0.93 → 0.80, 2nd: 0.77 → 0.65), meaning more passing even as passing efficiency fell and running held up. On manageable 2nd downs (≤6 to go), passes averaged −0.582 EPA against +0.266 for runs. After the injury, 1st-down play-calling flipped to run-heavy (1.40).

Caveats. Weeks 9–13 is only four games (187 early-down plays). A single game (Week 9 at PIT, −0.403 EPA) pulls the segment average down noticeably. The manageable 2nd-down splits are 15–27 plays per group. Treat Findings 4 and 5 as signals worth investigating, not proof.
