2025 Colts Offense: Soft Schedule or Real Decline?¶

Hypothesis: the Colts' hot start was driven by facing easier defenses early, and the offense regressed once the schedule got tougher.

Second question: how much of the late-season collapse comes from Daniel Jones' Week 14 injury instead?

The analysis focuses on early downs (1st and 2nd) and splits the 2025 regular season into three segments:

Segment Weeks Starting QB
Early 1–8 Daniel Jones
Late 9–13 Daniel Jones
Post-injury 14–18 Riley Leonard / Philip Rivers

Run python ingest.py first to build nfl_data.db.

In [1]:
import sqlite3
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

conn = sqlite3.connect('nfl_data.db')
sns.set_style('whitegrid')

# Every query uses the same segment definition, so it lives in one place.
# Each segment has an explicit upper bound: nothing after Week 13 can leak into 'Late'.
SEGMENTS = ['Early (1-8)', 'Late (9-13)', 'Post-injury (14-18)']
SEGMENT_SQL = """
    CASE
        WHEN week <= 8 THEN 'Early (1-8)'
        WHEN week <= 13 THEN 'Late (9-13)'
        ELSE 'Post-injury (14-18)'
    END
"""

# 2025 regular-season early-down run/pass plays
EARLY_DOWN_FILTER = """
    season = 2025
    AND season_type = 'REG'
    AND play_type IN ('run', 'pass')
    AND down IN (1, 2)
"""

2. Load Colts early-down plays¶

One query pulls every Colts 1st/2nd down run or pass, tagged with its segment. The sanity check below proves each segment only contains its own weeks.

In [3]:
query = f"""
SELECT
    week,
    {SEGMENT_SQL} AS segment,
    defteam,
    down,
    ydstogo,
    play_type,
    run_location,
    yards_gained,
    epa
FROM pbp_data
WHERE posteam = 'IND'
  AND {EARLY_DOWN_FILTER}
"""
colts = pd.read_sql_query(query, conn)
colts['segment'] = pd.Categorical(colts['segment'], categories=SEGMENTS, ordered=True)
colts['down'] = colts['down'].astype(int)

# Success: gain >= 4 yards on 1st down, or >= half the yards to go on 2nd down
colts['is_success'] = (
    ((colts['down'] == 1) & (colts['yards_gained'] >= 4)) |
    ((colts['down'] == 2) & (colts['yards_gained'] >= colts['ydstogo'] / 2))
).astype(int)

# Sanity check: first and last week in each segment
colts.groupby('segment', observed=True)['week'].agg(first_week='min', last_week='max', plays='count')

3. Testing the hypothesis: how tough were the Colts' opponents?¶

Each defense is rated by the average early-down EPA it allowed over the full 2025 regular season, counting only its games against other teams so the Colts' own results don't affect the rating. Lower EPA allowed = better defense. Rank 1 is the best defense in the league.

A full-season rating is more stable than one built from a handful of games in each segment.

In [4]:
query = f"""
SELECT
    defteam,
    AVG(epa) AS epa_allowed,
    RANK() OVER (ORDER BY AVG(epa)) AS def_rank
FROM pbp_data
WHERE {EARLY_DOWN_FILTER}
  AND posteam != 'IND'
GROUP BY defteam
"""
def_ratings = pd.read_sql_query(query, conn)

league_avg = pd.read_sql_query(f"SELECT AVG(epa) AS epa FROM pbp_data WHERE {EARLY_DOWN_FILTER}", conn)['epa'][0]
print(f"League-average early-down EPA per play: {league_avg:+.3f}")

# One row per Colts game, matched to that opponent's rating
games = colts.groupby(['segment', 'week', 'defteam'], observed=True).agg(colts_epa=('epa', 'mean')).reset_index()
games = games.merge(def_ratings, on='defteam', how='left')

# Positive = the Colts did better than that defense usually allows
games['epa_over_expected'] = games['colts_epa'] - games['epa_allowed']

print(games.round(3).to_string(index=False))

7. Run game: inside vs. outside¶

run_location of middle is treated as an inside run; left/right as outside. Plays with no recorded location are dropped rather than lumped in with outside runs.

Findings¶

Segment Avg opponent defense rank (1 = best) EPA opponents allow Colts EPA/play Colts vs. expected Success rate
Early (1–8) 16.6 +0.014 +0.202 +0.189 57.8%
Late (9–13) 11.3 −0.046 +0.031 +0.077 56.1%
Post-injury (14–18) 9.6 −0.045 −0.184 −0.140 42.2%

1. The schedule did get tougher. The Colts went from facing middle-of-the-league defenses in Weeks 1–8 to top-10-caliber defenses for the rest of the season.

2. But the hot start wasn't a soft schedule. Early opponents were average, not easy, and the Colts beat what those defenses usually allowed by +0.189 EPA per play. That includes two of the league's best defenses: Denver (#2, +0.420 over expected) and the Chargers (#4, +0.271).

3. Schedule explains part of the Weeks 9–13 decline, not all of it. Tougher defenses account for about 0.06 EPA per play, roughly a third of the 0.17 drop. After adjusting for opponents, the offense still slipped from +0.189 to +0.077 over expected.

4. The injury, not the schedule, explains the collapse. Weeks 9–13 and 14–18 had equally tough opponents (−0.046 vs −0.045 EPA allowed), yet the Colts went from +0.031 to −0.184 EPA per play once the backups took over.

5. The pre-injury slide was in the passing game. 1st-down pass EPA fell from +0.292 to +0.107 and 2nd-down pass EPA from +0.186 to −0.196. The run game held up: 2nd-down runs (+0.211 → +0.354) and inside runs (+0.059 → +0.231) both improved.

6. Play-calling moved toward the weaker option. In Weeks 9–13 the run/pass ratio dropped on both 1st down (0.93 → 0.80) and 2nd down (0.77 → 0.65), meaning more passing even as the pass game faded. On manageable 2nd downs (≤6 to go), passes averaged −0.582 EPA against +0.266 for runs.

Caveats. Weeks 9–13 is only four games (187 early-down plays) and Weeks 14–18 is five, so single games move segment averages a lot. The manageable 2nd-down splits are 15–27 plays per group. Defensive ratings are based on early-down EPA only.
